# Aetheria R11 Final

## What changed

### 1. Hero truth and audience clarity
- Added explicit mechanism language so the homepage explains that consequential requests become structured proposals before execution.
- Added audience clarity above the fold for organizations that require explicit control.
- Added high-consequence deployment context pills in the hero.
- Strengthened the blocked-action hero artifact so it reads like a real denial trace.

### 2. Category and navigation sharpening
- Renamed primary navigation labels to better match Aetheria's category posture:
  - How It Works → Execution Model
  - Platform → System
  - Use Cases → Deployment
  - Proof → Verification
- Updated major page kickers and intro copy to match the stronger category language.
- Added controlled power statements to the homepage, system page, and architecture page.

### 3. Proof and verification surface upgrade
- Rebuilt the default verification artifact around a more concrete portable proof packet.
- Added a public sample proof packet JSON download.
- Added an on-page preview block so verification feels like an artifact, not only a concept.
- Strengthened proof-page framing around portable verification outside the live runtime.

### 4. Public-language cleanup
- Replaced some internal phrasing with more public-facing technical language.
- Clarified architecture copy around the contract layer, runtime enforcement layer, and capability layer.
- Clarified platform copy so shipped surfaces feel real without sounding internal-only.

### 5. Rhythm and polish
- Tightened spacing and pacing across major homepage sections.
- Increased hero-to-core transition breathing room.
- Added styling for the new hero context row and proof sample panel.

### 6. SEO and metadata upgrade
- Updated default metadata and route-level descriptions to include:
  - governed AI infrastructure
  - AI governance system
  - AI action authorization
  - AI execution enforcement
- Strengthened descriptions for home, execution model, system, verification, architecture, and company pages.
